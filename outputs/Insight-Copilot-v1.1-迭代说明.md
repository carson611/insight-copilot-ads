# Insight Copilot v1.1 迭代说明

## 版本定位

v1.1 是 Demo 产品化打磨版。

本版本目标不是接入真实大模型 API，也不是解决所有上传字段适配问题，而是把 Day 5 MVP 从“能跑”提升到“更像真实产品、能给别人体验、能用于面试展示”的状态。

## 需求来源

本次迭代来自对当前 Demo 的体验走查，核心问题包括：

- 页面存在不专业的灰色备注。
- 常见业务问题中有部分问题无法得到对应分析。
- 周报页面缺少“选择周期 + 点击生成”的真实交互。
- 只支持本周 vs 上周，缺少多周趋势观察。
- 缺少维度透视分析。
- AI 生成结果缺少理性使用提示。

## 已完成优化

### 1. Copilot 问答补齐

新增支持的问题：

- 本周收入为什么下降？
- 投放成本为什么上涨？
- 哪个渠道最值得加预算？
- 帮我给老板写三条业务结论

保留并优化原有问题：

- 本周转化率为什么下降？
- 哪个渠道 ROI 最差？
- 哪个渠道拖累最大？
- 帮我生成一份业务周报

### 2. 周报生成工作流

周报页从静态文本改为：

1. 用户选择自然周。
2. 点击“生成周报”。
3. 系统基于所选周期与上一周期生成周报草稿。

如果选择的是第一个周期，系统会输出单周期概览，并提示没有上一周期可对比。

### 3. 多周趋势分析

指标看板新增“多周趋势”模块。

当前支持查看：

- 收入
- 订单量
- 成本
- 下单转化率
- ROI

### 4. 维度透视分析

指标看板新增“维度透视分析”模块。

当前支持：

- 按渠道分析
- 按地区分析
- 按设备分析

当前支持指标：

- 收入
- 订单量
- 成本
- 下单转化率
- ROI

### 5. 上传反馈增强

上传成功后，左侧会展示：

- 文件名
- 数据行数
- 日期范围
- 识别到的渠道、设备、地区数量
- 系统自动计算的派生指标

如果上传数据存在轻微问题，会给出数据质量提示。

### 6. AI 结果提示

Copilot 分析结果和周报生成前新增提示：

“AI 结果提示：以下结论由系统基于当前数据和固定指标口径计算生成，请结合业务背景理性判断。”

这用于体现 AI 产品中的可信边界和用户风险提示。

### 7. 页面说明收敛

删除或减少主流程中的灰色说明文字，让页面更像可操作产品，而不是说明文档。

## 当前未做但必须后续做

这些能力复杂，但对秋招竞争力有价值，不能放弃，只是排到 v1.2 / v2：

- 字段映射确认
- 上传历史文件选择
- 品类、广告类型、活动类型等新字段
- 更完整的数据校验与错误恢复
- 真实自然语言问答
- LLM API 接入
- 结果置信度、口径引用、幻觉防控
- 权限控制与敏感字段处理

## v1.2 目标

v1.2 的核心目标是解决“别人上传自己的表格怎么办”。

优先做：

- 上传后字段预览
- 用户手动选择字段映射
- 标准字段说明
- 上传历史 / 样例数据选择
- 样例数据升级：品类、广告类型、活动类型

## 用户测试建议

做到 v1.2 后，可以找同学、产品/运营方向朋友、实习同事体验。

重点收集：

- 是否知道上传什么数据。
- 上传失败时是否知道怎么改。
- 看板是否能快速看懂业务问题。
- Copilot 回答是否像真实业务分析。
- 周报是否能直接复用。
- 哪些功能最值得接入大模型。
