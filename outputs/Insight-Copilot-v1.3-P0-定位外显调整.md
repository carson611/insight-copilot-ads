# Insight Copilot v1.3 P0 定位外显调整

## 背景

v1.2 的实际能力已经是垂直场景：电商广告投放效果分析。

当前 Demo 支持的字段、问题和归因逻辑都围绕渠道、广告类型、活动类型、曝光、点击、注册、支付订单、GMV、广告消耗和 ROI 展开，并不适合直接分析科研、财务、人事等其他领域数据。

但 v1.2 的外显名称和页面表达仍偏“通用数据分析 Copilot”，容易让用户误以为它应该支持任意 CSV / Excel 分析，从而产生“直接让 Codex 生成一个页面有什么区别”的质疑。

## P0 目标

先不扩展通用数据分析能力，也不优先做大规模 UI 重设计。

P0 是把 Demo 的产品定位外显改成：

> Insight Copilot for Ads / 电商广告投放效果分析 Copilot

让用户第一眼就知道它服务的是电商广告投放复盘，而不是万能数据分析工具。

## 本次已调整内容

1. 页面标题从 `Insight Copilot` 调整为 `Insight Copilot for Ads`。
2. 页面副标题明确为“电商广告投放效果分析 Copilot”。
3. 顶部新增垂直定位信息：
   - 核心场景：电商广告投放周复盘
   - 分析对象：渠道、品类、广告类型、活动类型
   - 关键指标：曝光、点击、注册、订单、GMV、广告消耗、ROI
4. 侧边栏从“数据与筛选”调整为“投放数据与筛选”。
5. 上传入口从“上传 CSV / Excel”调整为“上传广告投放 CSV / Excel”。
6. 样例数据名称调整为“电商广告样例数据”。
7. Tabs 调整为：
   - 投放看板
   - 投放 Copilot
   - 投放周报
   - 数据口径
8. 问题模板改成广告投放复盘口径，例如：
   - 本周广告投放转化率为什么下降？
   - 哪个投放渠道 ROI 最差？
   - 广告消耗为什么上涨？
   - 帮我生成一份广告投放周报
9. 指标展示口径从“收入 / 成本”强化为“GMV / 广告消耗”。
10. 输出建议标题从“产品动作建议”调整为“投放动作建议”。

## 当前产品边界

当前 Demo 仍然是本地规则问答 + 指标计算版本，尚未接入真实 LLM API。

它的差异化不在于“能不能生成代码”，而在于把电商广告投放复盘中的固定流程沉淀为产品闭环：

数据接入 -> 字段映射 -> 指标看板 -> 异常识别 -> 维度归因 -> 投放动作建议 -> 周报草稿。

## 后续 UI 方向

现有 UI 仍然偏简单，后续可以进入 v1.3 P1 或 v1.4 做界面重设计。

优先方向：

- 首页从普通看板升级为“广告投放周复盘工作台”。
- 增加“本周异常摘要”区域。
- 将归因结果做成更清晰的问题链路：曝光 -> 点击 -> 注册 -> 下单 -> ROI。
- 将周报结果升级为可复制的结构化报告。
- 增加空状态、错误状态和上传指引。

但在这些之前，P0 必须先完成定位外显统一，避免产品看起来像一个能力不足的通用分析工具。
