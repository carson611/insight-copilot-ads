# 03 ROI 与预算效率诊断

## KB-ROI-001 ROI 下降分析框架

- 适用问题：ROI 为什么下降、投产比变差、广告不赚钱。
- 触发词：ROI、投产比、ROAS、回报、投产下降、不赚钱、亏、低效。
- 核心指标：ROI、GMV、广告消耗、支付订单量、下单转化率、客单价。
- 分析路径：
  1. 先判断 ROI = GMV / 广告消耗 中哪一端变化更明显。
  2. GMV 下降时，继续拆订单量和客单价。
  3. 广告消耗上涨时，继续拆渠道消耗和渠道 ROI。
  4. 找出高消耗低 ROI 渠道，判断是否拉低整体效率。
  5. 结合多周趋势，判断是单周波动还是持续走弱。
- 推荐图表：渠道 ROI 排名、成本收益矩阵、ROI 多周趋势、核心指标对比表。
- 回答要求：必须同时提 GMV 和消耗，不能只看 ROI 排名。
- 风险边界：ROI 下降不能直接归因为“渠道变差”，需要结合流量规模和成本结构。

## KB-ROI-002 高消耗低 ROI 识别

- 适用问题：哪个渠道烧钱不赚钱、哪个渠道浪费预算、应该砍哪个渠道。
- 触发词：烧钱不赚钱、浪费、低效、砍预算、哪个渠道不划算、亏。
- 核心指标：渠道消耗、渠道 ROI、渠道 GMV、渠道订单量。
- 分析路径：
  1. 按渠道计算本周 ROI。
  2. 识别 ROI 低于整体均值且消耗高于整体均值的渠道。
  3. 对该渠道判断 GMV 是否同步贡献不足。
  4. 如果低 ROI 且高消耗，建议降预算或做分组实验。
  5. 如果低 ROI 但消耗低，可作为观察项。
- 推荐图表：成本收益矩阵、渠道 ROI 条形图、渠道消耗排行。
- 回答要求：用“优先控制”而不是“立即砍掉”，保留实验空间。
- 风险边界：预算决策还需要考虑品牌曝光、新客价值和长期转化，当前 Demo 只看短期效果。

## KB-ROI-003 加预算判断

- 适用问题：哪个渠道值得加预算、应该投哪个、预算怎么分。
- 触发词：加预算、加投、放量、扩量、预算分配、值得投、优先投。
- 核心指标：渠道 ROI、渠道 GMV、渠道消耗、订单量、下单转化率。
- 分析路径：
  1. 优先筛选 ROI 高且 GMV 有一定规模的渠道。
  2. 排除 ROI 高但样本量过小的渠道。
  3. 看多周趋势是否稳定，避免因单周高 ROI 误判。
  4. 加预算建议采用小步实验，而不是一次性大幅倾斜。
- 推荐图表：渠道 ROI 排名、成本收益矩阵、多周 ROI 趋势。
- 回答要求：输出“建议加预算候选”和“谨慎观察候选”。
- 风险边界：当前 Demo 没有边际 ROI 和流量天花板，不能承诺加预算后 ROI 仍然稳定。

## KB-ROI-004 ROI 与转化率联动

- 适用问题：ROI 下降是不是因为转化率下降、投产和转化有什么关系。
- 触发词：ROI 和转化、投产和下单、效率下降、转化影响 ROI。
- 核心指标：ROI、下单转化率、订单量、GMV、广告消耗。
- 分析路径：
  1. 如果下单转化率下降且 ROI 下降，说明成交承接可能影响投产效率。
  2. 如果下单转化率稳定但 ROI 下降，优先看客单价下降或成本上涨。
  3. 如果下单转化率下降但 ROI 稳定，可能由客单价提升或成本下降抵消。
- 推荐图表：ROI 趋势图、下单转化率趋势图、核心指标对比表。
- 回答要求：解释指标之间的关系，而不是只给单一结论。
- 风险边界：相关性不等于因果，需要补充更细数据验证。
