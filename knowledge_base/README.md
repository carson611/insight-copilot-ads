# Insight Copilot for Ads RAG Knowledge Base v0.2

## 说明

这是 Insight Copilot for Ads 的第一版电商广告投放分析知识库，用于增强 Copilot 问答和周报生成能力。

本版本不是训练数据，也不是外部资料全文搬运，而是围绕当前 Demo 支持的字段和电商广告周复盘场景整理的产品分析知识卡片。后续接入 RAG 时，系统可以按知识卡标题、触发词、适用问题和推荐图表进行检索。

## 当前覆盖范围

- 指标口径：曝光、点击、注册、订单、GMV、广告消耗、CTR、注册转化率、下单转化率、CVR、ROI、CPC、CPM、CPA、单订单成本、客单价、贡献占比。
- 诊断框架：转化率下降、ROI 下降、广告消耗上涨、GMV 下滑、渠道拖累、预算分配。
- 业务维度：渠道、商品品类、广告类型、活动类型、地区、设备。
- 渠道经验：抖音、小红书、搜索广告、B站、自然流量。
- 图表规则：不同问题对应的推荐图表和证据组合。
- 漏斗阶段：CTR、注册转化、下单承接、ROI 与规模关系等细分诊断。
- 输出风格：Copilot 简洁回答、周报节奏、证据优先和风险措辞模板。
- 安全边界：幻觉控制、数据安全、归因边界、口径一致。

## 卡片格式

每张知识卡建议保持以下结构：

- `适用问题`：用户可能问什么。
- `触发词`：检索时可匹配的关键词。
- `核心指标`：回答必须关注哪些指标。
- `核心定义`：指标公式或口径说明。
- `分析路径`：业务拆解步骤。
- `推荐图表`：应该由系统渲染哪些真实图表。
- `回答要求`：LLM 应如何表达。
- `风险边界`：哪些结论不能说死。

## 使用原则

1. LLM 不直接计算指标，指标由 pandas / 规则层计算。
2. LLM 不直接生成图表，图表计划由系统内部生成并校验，图表由系统根据数据真实渲染。
3. RAG 只提供分析框架和表达模板，不提供虚构业务事实。
4. 归因必须用“可能原因”“待验证假设”，不能说成已验证事实。
5. 检索结果优先保留不同主题的知识卡，避免同一类卡片重复堆叠。
6. 后续如引用平台官方口径，需要在知识卡中补充来源链接。
