# 07 周报与表达模板

## KB-REPORT-001 标准投放周报结构

- 适用问题：生成一份广告投放周报。
- 触发词：周报、报告、复盘、本周总结。
- 推荐结构：
  1. 本周总体判断：一句话说明 GMV、ROI、转化率的核心变化。
  2. 核心指标表现：列出 GMV、消耗、ROI、订单、下单转化率。
  3. 渠道与维度表现：指出表现最好和拖累最大的渠道/维度。
  4. 异常归因与待验证假设：拆流量质量、转化承接、成本结构、商品活动。
  5. 下周动作建议：控低效、保高效、验证假设、补充数据。
  6. 风险提示：说明数据边界和不能确认的原因。
- 回答要求：纯文字 Markdown，不生成表格和图表。
- 风险边界：不能虚构用户规模、上线效果、真实业务动作。

## KB-REPORT-002 老板版三条结论

- 适用问题：帮我给老板写三条结论、管理层摘要。
- 触发词：老板、三条、管理层、结论、汇报。
- 推荐结构：
  1. 经营结果：GMV / 收入变化。
  2. 投放效率：ROI 和广告消耗变化。
  3. 异常来源：拖累最大的渠道或维度。
- 回答要求：
  - 每条结论都要短。
  - 每条都必须包含关键数值。
  - 先说结论，再说证据。
- 示例句式：
  - 本周 GMV 较上周下降，主要压力来自订单量和下单转化率同步走弱。
  - 广告消耗上升但 ROI 下降，说明预算效率承压。
  - 渠道侧优先关注某渠道，其转化率下降幅度最大且当前 ROI 偏低。
- 风险边界：老板版不能写过多待验证细节，但必须保留“可能原因”的措辞。

## KB-REPORT-003 运营版复盘表达

- 适用问题：写给运营同学的复盘。
- 触发词：运营、复盘、动作、优化建议。
- 推荐结构：
  1. 哪些指标异常。
  2. 异常集中在哪些渠道/品类/活动。
  3. 可能原因是什么。
  4. 下周怎么验证。
  5. 要补哪些数据。
- 回答要求：比老板版更细，动作建议要可执行。
- 风险边界：不能直接给“必然提升”的承诺。

## KB-REPORT-004 投放版优化建议

- 适用问题：投放同学下周怎么调预算、怎么优化渠道。
- 触发词：投放、预算、加投、控量、优化、下周动作。
- 推荐结构：
  1. 高 ROI 渠道：保留或小步加投。
  2. 高消耗低 ROI 渠道：控预算或分组实验。
  3. 转化下降渠道：排查素材、人群、落地页、价格权益。
  4. 观察渠道：继续监控多周趋势。
- 回答要求：动作要分优先级，不要一刀切。
- 风险边界：当前 Demo 不含边际成本，不能建议大幅加投。

## KB-REPORT-005 指标升级版周报

- 适用问题：在现有周报基础上补充 CVR、CPA、贡献占比。
- 触发词：周报升级、指标补充、CVR、CPA、贡献占比、结构变化。
- 推荐结构：
  1. 本周总体判断：GMV、ROI、CVR、CPA 是否同向变化。
  2. 核心指标表现：补充收入贡献、消耗占比和订单贡献。
  3. 渠道与维度表现：指出拖累最大的渠道和贡献最高的渠道。
  4. 异常归因与待验证假设：拆流量质量、成交承接、成本结构和结构变化。
  5. 下周动作建议：保高效、控低效、补数据、做小流量验证。
- 回答要求：仍然只输出纯文字，不在周报正文里塞图表计划。
- 风险边界：周报里可以写“建议排查”，不能写成已验证结论。
