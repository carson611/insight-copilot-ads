# 01 指标字典

## KB-METRIC-001 曝光量

- 适用问题：流量规模、投放触达、渠道流量是否变少。
- 触发词：曝光、展现、流量、触达、没人看、量少。
- 核心定义：广告被展示的次数。
- 分析路径：
  1. 先看曝光量环比是否下降。
  2. 再看点击量是否同步下降。
  3. 如果曝光下降但 CTR 稳定，优先判断为流量规模问题。
  4. 如果曝光稳定但点击下降，优先进入点击质量或素材吸引力分析。
- 推荐图表：曝光趋势图、渠道曝光排行、核心指标对比表。
- 风险边界：仅凭曝光下降不能判断是平台限流、预算不足还是竞争加剧，需要结合预算、出价、排期等外部信息。

## KB-METRIC-002 点击量与 CTR

- 适用问题：点击变少、素材吸引力、广告是否有人点。
- 触发词：点击、CTR、点击率、没人点、素材、吸引力。
- 核心定义：CTR = 点击量 / 曝光量。
- 分析路径：
  1. 曝光和点击同时下降时，先判断流量规模变化。
  2. 曝光稳定但 CTR 下降时，优先看素材、标题、定向人群、广告位匹配。
  3. CTR 上升但下单转化率下降时，可能是点击人群质量下降或落地页承接不足。
- 推荐图表：CTR 趋势图、渠道 CTR 排行、曝光-点击漏斗。
- 风险边界：CTR 只能说明点击意愿，不能直接说明成交质量。

## KB-METRIC-003 注册转化率

- 适用问题：点击后注册少、前端承接问题、线索获取效率。
- 触发词：注册、注册率、线索、点击后没人注册、前端转化。
- 核心定义：注册转化率 = 注册量 / 点击量。
- 分析路径：
  1. 点击量稳定但注册转化率下降，优先看落地页、注册流程、表单门槛。
  2. CTR 和注册转化率同时下降，可能是流量人群与产品匹配度下降。
  3. 注册转化率稳定但下单转化率下降，问题更可能在注册后的商品、价格或成交承接。
- 推荐图表：注册转化率趋势图、渠道注册转化率排行、点击-注册-订单漏斗。
- 风险边界：没有页面访问、跳出率、表单错误率时，不能断言是落地页问题。

## KB-METRIC-004 下单转化率

- 适用问题：转化率下降、订单少、成交承接变差。
- 触发词：转化、下单率、成单、订单少、下滑、掉了、承接。
- 核心定义：下单转化率 = 支付订单量 / 注册量。
- 分析路径：
  1. 先看整体下单转化率环比变化。
  2. 再拆渠道，看哪个渠道下单转化率下降百分点最大。
  3. 继续拆品类、广告类型、活动类型，判断问题是否集中在局部维度。
  4. 如果转化率下降同时 ROI 下降，说明效率问题已经影响投产。
- 推荐图表：下单转化率趋势图、渠道转化变化图、维度拖累表、核心指标对比表。
- 风险边界：没有价格、库存、页面行为、客服和履约数据时，不能确认真实业务原因。

## KB-METRIC-005 GMV / 收入

- 适用问题：收入下降、GMV 下滑、卖不动、订单少。
- 触发词：GMV、收入、营收、成交额、销售额、卖不动、订单少。
- 核心定义：GMV / 收入为广告带来的成交金额。
- 分析路径：
  1. GMV = 支付订单量 * 客单价。
  2. GMV 下降要拆成订单量下降和客单价下降。
  3. 订单量下降继续拆曝光、点击、注册、下单转化率。
  4. 客单价下降需要结合商品结构、活动折扣和低价品类占比。
- 推荐图表：GMV 趋势图、渠道 GMV 排行、订单量与客单价对比、核心指标对比表。
- 风险边界：当前 Demo 没有 SKU 和价格明细，因此客单价原因只能作为待验证假设。

## KB-METRIC-006 广告消耗 / 投放成本

- 适用问题：成本上涨、烧钱、花费增加、预算效率变差。
- 触发词：成本、消耗、花费、烧钱、变贵、投放成本、预算花完。
- 核心定义：广告消耗为投放产生的广告成本。
- 分析路径：
  1. 先看总消耗是否上涨。
  2. 再看 GMV 是否同步上涨。如果成本涨但 GMV 没涨，效率恶化。
  3. 拆渠道消耗，看是否低 ROI 渠道消耗占比上升。
  4. 结合点击、订单和转化率，判断成本上涨是量增带来的，还是效率下降带来的。
- 推荐图表：广告消耗趋势图、渠道消耗排行、成本收益矩阵、核心指标对比表。
- 风险边界：当前 Demo 没有 CPC、CPM、出价和竞价环境字段，不能直接判断成本上涨来自出价或竞争。

## KB-METRIC-007 ROI / ROAS

- 适用问题：ROI 最差、投产比下降、烧钱不赚钱、预算分配。
- 触发词：ROI、ROAS、投产、投产比、回报、不赚钱、亏、低效、浪费。
- 核心定义：ROI = GMV / 广告消耗。部分广告平台也常用 ROAS 表达广告收入回报。
- 分析路径：
  1. ROI 下降可能由 GMV 下降、成本上涨或两者共同导致。
  2. 先看整体 ROI 环比，再拆渠道 ROI 排名。
  3. 结合成本收益矩阵，识别“高消耗低 ROI”渠道。
  4. 对高 ROI 渠道考虑保留或加预算，对低 ROI 高消耗渠道考虑控量或实验优化。
- 推荐图表：渠道 ROI 排行、成本收益矩阵、ROI 多周趋势、核心指标对比表。
- 风险边界：ROI 高不一定代表可无限加预算，仍需验证流量天花板、边际成本和库存承接。

## KB-METRIC-008 客单价

- 适用问题：收入下降但订单没明显下降、成交结构变化。
- 触发词：客单价、AOV、单价、低价、成交结构、商品结构。
- 核心定义：客单价 = GMV / 支付订单量。
- 分析路径：
  1. GMV 下降但订单量稳定时，优先看客单价变化。
  2. 客单价下降可能来自低价品类占比提升、折扣加深、套餐结构变化。
  3. 当前 Demo 可用商品品类维度做初步验证。
- 推荐图表：客单价趋势图、品类 GMV / 订单透视表、核心指标对比表。
- 风险边界：没有 SKU、价格、优惠券和订单明细时，不能确认具体价格策略变化。

## KB-METRIC-009 CPC / 点击成本

- 适用问题：CPC 为什么上涨、点击成本变高、哪个渠道点击成本最高。
- 触发词：CPC、点击成本、单次点击成本、点击变贵、买量变贵。
- 核心定义：CPC = 广告消耗 / 点击量。
- 分析路径：
  1. 先看整体 CPC 环比是否上涨。
  2. 同时拆广告消耗和点击量，判断是成本上涨、点击减少，还是两者共同导致。
  3. 按渠道拆 CPC，识别点击成本最高且消耗较高的渠道。
  4. 结合 CTR 和 ROI，判断高 CPC 是否已经影响点击质量和投产效率。
- 推荐图表：CPC 趋势图、渠道 CPC 排行、核心指标对比表、成本收益矩阵。
- 风险边界：当前 Demo 没有出价、关键词竞争度和广告位字段，不能直接判断 CPC 上涨来自平台竞价。

## KB-METRIC-010 CPM / 千次曝光成本

- 适用问题：曝光成本为什么上涨、CPM 变高、买曝光变贵。
- 触发词：CPM、千次曝光成本、曝光成本、展现成本。
- 核心定义：CPM = 广告消耗 / 曝光量 * 1000。
- 分析路径：
  1. 先看 CPM 环比变化。
  2. 拆广告消耗和曝光量，判断曝光成本是否整体抬升。
  3. 按渠道拆 CPM，识别曝光成本偏高的渠道。
  4. 结合 CTR 判断高 CPM 是否换来了足够点击效率。
- 推荐图表：CPM 趋势图、渠道 CPM 排行、核心指标对比表。
- 风险边界：没有广告位、竞价、频控和人群包数据时，不能确认 CPM 变化原因。

## KB-METRIC-011 单订单成本

- 适用问题：获客成本高、成交成本高、CPA 为什么上涨、订单成本变贵。
- 触发词：CPA、获客成本、成交成本、订单成本、单订单成本。
- 核心定义：单订单成本 = 广告消耗 / 支付订单量。
- 分析路径：
  1. 先看单订单成本是否上涨。
  2. 同时拆广告消耗和订单量。
  3. 如果订单量下降但消耗不降，单订单成本会明显恶化。
  4. 继续拆渠道，定位高成本低订单的渠道。
- 推荐图表：单订单成本趋势图、渠道单订单成本排行、下单转化率趋势图、核心指标对比表。
- 风险边界：当前 Demo 只按订单数计算成本，不等同于真实用户 CAC 或 LTV 口径。

## KB-METRIC-012 CPA / 获客成本

- 适用问题：获客成本高、注册成本高、哪个渠道获客最贵。
- 触发词：CPA、获客成本、注册成本、单注册成本、拉新成本。
- 核心定义：CPA = 广告消耗 / 注册量。在当前 Demo 中，CPA 按注册口径计算，不等同于真实业务里的全链路 CAC。
- 分析路径：
  1. 先看整体 CPA 是否上涨。
  2. 再拆广告消耗和注册量，判断是成本抬升还是注册量下降。
  3. 按渠道找出 CPA 最高的渠道。
  4. 同时结合 CVR 和注册转化率，判断是前端流量质量还是注册承接问题。
- 推荐图表：CPA 趋势图、渠道 CPA 排行、点击-注册漏斗、核心指标对比表。
- 风险边界：没有落地页、表单错误和线索质量字段时，不能确认真实获客效率变化原因。

## KB-METRIC-013 CVR / 点击到订单转化率

- 适用问题：CVR 为什么下降、点击后没下单、成交转化变差。
- 触发词：CVR、点击到订单转化率、点击转化、点击后下单、点击后成交。
- 核心定义：CVR = 支付订单量 / 点击量。这个口径与下单转化率不同，后者是订单 / 注册。
- 分析路径：
  1. 先看整体 CVR 是否下降。
  2. 再拆渠道，找出 CVR 下降最明显的渠道。
  3. 结合 CTR、注册转化率和 ROI 判断问题在哪一段。
  4. 如果 CTR 稳定但 CVR 下降，优先怀疑点击后承接。
- 推荐图表：CVR 趋势图、渠道 CVR 排行、点击-订单漏斗、核心指标对比表。
- 风险边界：没有页面行为、价格、库存和活动权益字段时，不能确认成交承接问题的真实原因。

## KB-METRIC-014 GMV贡献占比

- 适用问题：哪个渠道收入贡献最大、收入结构是否变化。
- 触发词：GMV贡献、收入贡献、份额、结构、谁贡献最大。
- 核心定义：GMV贡献占比 = 渠道 GMV / 全部 GMV。
- 分析路径：
  1. 先看哪些渠道占据主要收入份额。
  2. 再看贡献占比是否比上周上升或下降。
  3. 如果高贡献渠道同时 ROI 稳定，可优先保留。
- 推荐图表：GMV贡献排行、GMV贡献趋势图、成本收益矩阵、核心指标对比表。
- 风险边界：贡献占比高不等于高效率，必须同时看 ROI 和消耗规模。

## KB-METRIC-015 广告消耗占比

- 适用问题：哪个渠道消耗占比最高、预算是否过度集中。
- 触发词：消耗占比、花费占比、成本占比、烧钱、结构。
- 核心定义：广告消耗占比 = 渠道消耗 / 全部消耗。
- 分析路径：
  1. 先看消耗是否集中在少数渠道。
  2. 再看高消耗渠道的 ROI 是否同步较差。
  3. 如果消耗占比上升但 ROI 下滑，说明预算结构可能失衡。
- 推荐图表：消耗占比排行、消耗占比趋势图、成本收益矩阵、核心指标对比表。
- 风险边界：消耗占比高可能只是规模大，不代表一定浪费。

## KB-METRIC-016 订单贡献占比

- 适用问题：哪个渠道订单贡献最大、订单结构是否变化。
- 触发词：订单贡献、支付订单占比、份额、结构。
- 核心定义：订单贡献占比 = 渠道订单量 / 全部订单量。
- 分析路径：
  1. 看订单主要由哪些渠道贡献。
  2. 结合下单转化率和 ROI 判断该渠道是否值得继续放量。
  3. 如果订单贡献集中但 CVR 下降，要警惕规模依赖。
- 推荐图表：订单贡献排行、订单贡献趋势图、渠道 CVR 排行、核心指标对比表。
- 风险边界：订单贡献高不代表客单价高或利润好。

## KB-METRIC-017 点击贡献占比

- 适用问题：哪个渠道带来最多点击、流量结构是否偏移。
- 触发词：点击贡献、点击份额、流量贡献、结构。
- 核心定义：点击贡献占比 = 渠道点击量 / 全部点击量。
- 分析路径：
  1. 先看流量主要由哪些渠道贡献。
  2. 再结合 CTR 和 CVR 判断流量是否只是“多点不成交”。
  3. 如果点击贡献高但订单贡献低，说明点击质量偏弱。
- 推荐图表：点击贡献排行、点击贡献趋势图、CTR 趋势图、核心指标对比表。
- 风险边界：点击贡献高只能说明流量规模大，不能直接说明业务质量好。

## KB-METRIC-018 注册贡献占比

- 适用问题：哪个渠道带来最多注册、线索结构是否变化。
- 触发词：注册贡献、线索贡献、注册份额、结构。
- 核心定义：注册贡献占比 = 渠道注册量 / 全部注册量。
- 分析路径：
  1. 看注册主要来自哪些渠道。
  2. 再结合 CPA 和 CVR 判断获客质量。
  3. 如果注册贡献提升但 CPA 也升高，要警惕投放放量过快。
- 推荐图表：注册贡献排行、注册贡献趋势图、渠道 CPA 排行、核心指标对比表。
- 风险边界：注册贡献高不一定等于真实线索质量好。

## KB-METRIC-019 曝光贡献占比

- 适用问题：哪个渠道贡献最多曝光、触达结构是否变化。
- 触发词：曝光贡献、触达份额、展现占比、结构。
- 核心定义：曝光贡献占比 = 渠道曝光量 / 全部曝光量。
- 分析路径：
  1. 先看曝光是否集中在少数渠道。
  2. 再结合 CTR 判断曝光是否有效。
  3. 如果曝光贡献上升但点击不涨，说明触达效率偏弱。
- 推荐图表：曝光贡献排行、曝光贡献趋势图、CTR 趋势图、核心指标对比表。
- 风险边界：曝光贡献高通常只代表触达规模，不代表业务结果好。
