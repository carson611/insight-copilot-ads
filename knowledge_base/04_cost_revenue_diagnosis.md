# 04 成本与收入诊断

## KB-COST-001 广告消耗上涨分析框架

- 适用问题：广告成本为什么上涨、为什么更烧钱、消耗变高是否合理。
- 触发词：成本上涨、消耗上涨、烧钱、花费增加、变贵、投放成本。
- 核心指标：广告消耗、GMV、ROI、点击量、订单量、下单转化率。
- 分析路径：
  1. 先判断消耗上涨是否带来 GMV 或订单同步增长。
  2. 如果消耗上涨但 GMV 未涨，说明效率变差。
  3. 拆渠道消耗，找出消耗增量最大的渠道。
  4. 看该渠道 ROI 是否低于整体平均水平。
  5. 如果低 ROI 渠道消耗扩大，是预算结构风险。
- 推荐图表：广告消耗趋势图、渠道消耗排行、成本收益矩阵、核心指标对比表。
- 回答要求：区分“规模增长带来的成本上涨”和“效率下降带来的成本上涨”。
- 风险边界：没有 CPC、CPM、出价字段时，不能断言是竞价成本上涨。

## KB-COST-002 成本上涨后的动作建议

- 适用问题：成本上涨后怎么办、要不要控预算。
- 触发词：控成本、控预算、降本、节流、成本优化。
- 核心指标：渠道消耗、渠道 ROI、GMV、订单量。
- 分析路径：
  1. 先保留高 ROI 且规模稳定的渠道预算。
  2. 对高消耗低 ROI 渠道做预算上限控制。
  3. 对成本上涨但 ROI 仍稳定的渠道继续观察。
  4. 对新增活动或新品投放单独评估，避免和常规投放混在一起。
- 推荐图表：成本收益矩阵、渠道 ROI 排名、渠道消耗排行。
- 回答要求：建议要体现分层，不要简单一刀切降预算。
- 风险边界：降预算可能影响流量规模，需提示有 GMV 下滑风险。

## KB-COST-003 CPC 上涨分析框架

- 适用问题：CPC 为什么上涨、点击成本变高、哪个渠道点击成本最高。
- 触发词：CPC、点击成本、买量变贵、点击变贵、单次点击成本。
- 核心指标：CPC、广告消耗、点击量、CTR、ROI、渠道 CPC。
- 分析路径：
  1. 先确认 CPC 是否环比上涨。
  2. 拆成本和点击量：成本涨、点击降，都会推高 CPC。
  3. 按渠道排序找 CPC 最高的渠道。
  4. 再看该渠道 CTR 和 ROI，判断高 CPC 是否同时伴随点击质量或投产问题。
  5. 如果高 CPC 渠道消耗也高，优先级高于高 CPC 但消耗很小的渠道。
- 推荐图表：CPC 趋势图、渠道 CPC 排行、核心指标对比表、成本收益矩阵。
- 回答要求：必须同时提成本和点击量，不能只说“成本上涨”。
- 风险边界：没有平台出价、关键词和竞争环境字段时，不能断言 CPC 上涨的真实原因。

## KB-REV-001 GMV 下滑分析框架

- 适用问题：GMV 为什么下降、收入为什么下降、卖不动了。
- 触发词：GMV、收入、营收、销售额、卖不动、成交少、订单少。
- 核心指标：GMV、支付订单量、客单价、下单转化率、广告消耗、ROI。
- 分析路径：
  1. 先判断 GMV 下降主要来自订单量下降还是客单价下降。
  2. 订单量下降时，继续拆曝光、点击、注册、下单转化率。
  3. 客单价下降时，拆商品品类和活动类型。
  4. 如果广告消耗上涨但 GMV 下滑，说明投放效率风险更高。
  5. 找出 GMV 下滑最明显的渠道或品类。
- 推荐图表：GMV 趋势图、渠道 GMV 排行、核心指标对比表、品类透视表。
- 回答要求：必须拆“量”和“价”，不要只说收入下降。
- 风险边界：当前 Demo 没有真实订单明细，客单价变化只能作为初步线索。

## KB-REV-002 收入下滑后的动作建议

- 适用问题：收入下降后怎么办、下周怎么拉回 GMV。
- 触发词：拉回、恢复、提升 GMV、收入优化、卖不动怎么办。
- 核心指标：GMV、订单量、客单价、ROI、下单转化率。
- 分析路径：
  1. 如果订单量下降，优先修复转化和渠道质量。
  2. 如果客单价下降，优先检查品类结构和活动权益。
  3. 如果低 ROI 渠道消耗扩大，应先控低效预算。
  4. 如果高 ROI 渠道规模稳定，可考虑小步加投。
- 推荐图表：GMV 趋势图、品类 GMV 排行、成本收益矩阵。
- 回答要求：动作建议要和收入下降的主要驱动对应。
- 风险边界：没有库存、价格和促销数据时，不能承诺具体 GMV 修复幅度。

## KB-COST-004 CPA 上涨分析框架

- 适用问题：获客成本为什么上涨、注册成本怎么变高、哪个渠道获客最贵。
- 触发词：CPA、获客成本、注册成本、单注册成本、拉新变贵。
- 核心指标：CPA、广告消耗、注册量、CVR、ROI、渠道 CPA。
- 分析路径：
  1. 先确认 CPA 是否环比上涨。
  2. 拆广告消耗和注册量，判断是成本抬升还是注册量下降。
  3. 按渠道排序找出 CPA 最高的渠道。
  4. 再结合 CVR 和注册转化率，判断是流量质量问题还是注册承接问题。
  5. 如果高 CPA 同时伴随低 ROI，优先级最高。
- 推荐图表：CPA 趋势图、渠道 CPA 排行、点击-注册漏斗、核心指标对比表。
- 回答要求：要把“CPA 上涨”和“真实获客效率恶化”分开写。
- 风险边界：没有表单、落地页、线索质量和竞价字段时，不能直接说出真实成本上涨原因。
