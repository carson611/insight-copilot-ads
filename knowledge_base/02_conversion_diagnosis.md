# 02 转化率下降诊断

## KB-CONV-001 整体转化率下降分析框架

- 适用问题：本周转化率为什么下降、下单变差、订单少了。
- 触发词：转化率下降、下单率下降、成单少、转化掉了、承接变差、为什么下降。
- 核心指标：曝光量、点击量、注册量、支付订单量、注册转化率、下单转化率、ROI。
- 分析路径：
  1. 判断下降发生在漏斗哪一段：曝光到点击、点击到注册、注册到下单。
  2. 如果 CTR 下降，优先看素材吸引力、人群匹配和广告位。
  3. 如果注册转化率下降，优先看落地页、注册流程、表单门槛。
  4. 如果下单转化率下降，优先看商品吸引力、价格权益、库存履约、活动承接。
  5. 拆渠道和品类，判断是整体下滑还是局部维度拖累。
- 推荐图表：下单转化率趋势图、渠道转化变化图、漏斗指标对比表、品类拖累图。
- 回答要求：先给整体结论，再指出拖累最大的渠道/维度，最后给待验证假设。
- 风险边界：没有页面行为、价格、库存和客服数据时，不能把原因说成事实。

## KB-CONV-002 渠道转化拖累分析

- 适用问题：哪个渠道拖累最大、谁导致转化下降、哪个渠道拉胯。
- 触发词：拖累、拖后腿、拉胯、谁导致、哪个渠道问题最大、锅。
- 核心指标：渠道下单转化率变化百分点、渠道 ROI、渠道 GMV、渠道消耗。
- 分析路径：
  1. 按渠道计算本周与上周下单转化率差值。
  2. 找出下降百分点最大的渠道。
  3. 判断该渠道 GMV 和消耗规模是否足够大。
  4. 如果下降大且消耗高，优先级最高。
  5. 如果下降大但规模小，作为观察项而不是主因。
- 推荐图表：渠道转化变化条形图、渠道归因拆解表、渠道 ROI 对比图。
- 回答要求：用“拖累最大”而不是“唯一原因”；说明影响规模。
- 风险边界：转化率下降百分点不等于收入拖累金额，需要结合渠道规模。

## KB-CONV-003 多维度转化归因

- 适用问题：是不是某个品类/广告类型/活动导致转化下降。
- 触发词：品类、类目、广告类型、活动类型、地区、设备、哪个维度。
- 核心指标：维度下单转化率变化、维度 ROI、维度 GMV、维度消耗。
- 分析路径：
  1. 先拆渠道，确认是否为渠道问题。
  2. 再拆品类，确认是否集中在特定商品结构。
  3. 再拆广告类型，确认是否与直播、种草、搜索等投放方式相关。
  4. 再拆活动类型，确认是否与促销周期、会员日或新品活动相关。
- 推荐图表：维度透视表、维度拖累图、维度 ROI 排名。
- 回答要求：按“渠道 -> 品类 -> 广告类型 -> 活动类型”的优先级描述。
- 风险边界：多维度同时异常时，需要提示可能存在样本重叠，不能简单相加。

## KB-CONV-004 转化下降的产品动作建议

- 适用问题：转化率下降后怎么办、下周怎么优化。
- 触发词：怎么办、建议、动作、优化、下周、解决。
- 核心指标：下单转化率、ROI、订单量、GMV、消耗。
- 分析路径：
  1. 对拖累最大渠道做素材、人群、落地页、价格权益排查。
  2. 对低 ROI 高消耗渠道做预算控制。
  3. 对高 ROI 渠道保留预算，避免误伤有效流量。
  4. 对疑似品类问题补充商品结构和库存数据验证。
- 推荐图表：渠道拖累图、成本收益矩阵、维度透视表。
- 回答要求：建议要分优先级，避免同时给过多动作。
- 风险边界：优化建议应表达为实验或排查方向，不能承诺转化提升。

## KB-CONV-005 CVR 下降分析框架

- 适用问题：CVR 为什么下降、点击后下单为什么变差、点击到订单转化率怎么掉了。
- 触发词：CVR、点击到订单转化率、点击转化、点击后下单、成交承接。
- 核心指标：点击量、支付订单量、CVR、CTR、注册转化率、ROI。
- 分析路径：
  1. 先判断整体 CVR 环比是否下降。
  2. 再拆渠道，找出 CVR 下降最大的渠道。
  3. 如果 CTR 稳定但 CVR 下降，优先怀疑点击后的承接链路。
  4. 如果 CTR 和 CVR 同时下降，优先怀疑流量质量或素材与人群匹配。
  5. 再结合 ROI 判断问题是否已经影响投放效率。
- 推荐图表：CVR 趋势图、渠道 CVR 排行、点击-订单漏斗、渠道 ROI 对比图。
- 回答要求：要明确区分“点击质量问题”和“成交承接问题”。
- 风险边界：没有价格、库存、页面行为和活动信息时，不能把原因说成已验证事实。

## KB-CONV-006 CVR 下降后的动作建议

- 适用问题：CVR 下降怎么办、点击后下单差怎么优化。
- 触发词：怎么办、优化、修复、下周动作、CVR 回升。
- 核心指标：CVR、CTR、注册转化率、订单量、ROI。
- 分析路径：
  1. 对 CVR 下降最明显的渠道先做小流量复盘。
  2. 如果 CTR 稳定，优先看落地页、价格权益、库存和支付链路。
  3. 如果 CTR 也下降，优先看流量质量、素材和人群匹配。
  4. 将低 CVR 且低 ROI 的渠道先做控量实验。
- 推荐图表：CVR 趋势图、渠道 CVR 排行、核心指标对比表、成本收益矩阵。
- 回答要求：动作建议要对应问题阶段，不要上来就统一降预算。
- 风险边界：没有更细颗粒度数据时，只能给排查方向，不能承诺结果。
